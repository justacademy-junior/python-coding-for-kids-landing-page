## How to Publish on GitHub Pages

1. Create a new repository named `python-coding-for-kids-landing-page`.
2. Upload `index.html` and `README.md` to the main branch.
3. Go to **Settings**, then **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and the `/ (root)` folder, then save.
5. Wait a minute, then open your Pages link.
